2) Installation de Evolve Tool  (si à la maison)

dotnet tool install --global Evolve.Tool 


3) Mettre à jour pour la version prerelease qui fonctionne avec .Net 8.0

dotnet tool update evolve.tool -g --prerelease


4) Migration

evolve migrate sqlserver -c "Data Source=.;Initial Catalog=BD_FF14;Integrated Security=True;Persist Security Info=False;Pooling=False;MultipleActiveResultSets=False;Encrypt=False;TrustServerCertificate=False" -s Personnage -s Item -s SGC -s Clients --target-version 2.2


5) Scaffold

dotnet ef dbcontext scaffold Name=BD_FF14 Microsoft.EntityFrameworkCore.SqlServer -o Models --context-dir Data --context BD_FF14Context --data-annotations --force
